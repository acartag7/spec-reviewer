# Spec Reviewer v0.6.0

## Better Markdown review

- Markdown tables keep usable column layout instead of collapsing into hard-to-read text.
- Mermaid diagrams render in the Rendered view and retain visible change markers.

## Safer feedback handoffs

- Copying feedback creates a durable checkpoint before it uses the clipboard.
- The review flow reserves capacity for its final Finish checkpoint and preserves the reviewer’s selected text.
- A document without a completed baseline now states that clearly instead of presenting an empty comparison as a change set.

## Upgrade

No manual migration is required. Existing review data remains available locally.
