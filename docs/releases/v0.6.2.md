# Spec Reviewer v0.6.2

## Review UI restored

- Compiled release binaries now serve the completed Vite application without
  rebundling it, so the review workspace loads instead of showing a blank page.
- The binary and release-artifact builds use the same embedded web assets.

## Packaging verification

- Binary smoke tests now verify that every built web asset is served
  byte-for-byte, preventing packaging rewrites from silently breaking the UI.

## Upgrade

Upgrade from v0.6.1 as soon as practical. No manual migration is required, and
existing local review data remains available.
