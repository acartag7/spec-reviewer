# Spec Reviewer v0.6.1

## Reliable review reopening

- The Codex and Claude skill templates now tell agents how to reopen a review
  when its session ID is not available in the recent-session list.
- Agents can reopen the original Markdown source directly after a checkpoint-only
  handoff or finish, and when an older saved review falls outside that list.

## Packaging reliability

- The local Homebrew smoke test now keeps its temporary workspace separate from
  Homebrew's own temporary-directory handling.

## Upgrade

No manual migration is required. Existing review data remains available locally.
